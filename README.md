# 아기 냠냠 대모험

아기가 미로를 기어다니며 과자를 먹는 팩맨 스타일 미니 게임입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 특징

- 캐릭터: 실제 아기 영상에서 잘라낸 4프레임 기어가기 애니메이션 (`assets/baby_crawl.png`)
- 효과음: 아기 웃음소리 녹음을 잘라 사용
  - 과자 20개마다 킥킥 (`giggle1.mp3`, `giggle2.mp3`)
  - 🍼 젖병 먹기 → 웃음 (`laugh1.mp3`, `laugh2.mp3`)
  - 유령에게 잡힘 → 속상한 소리 (`fail.mp3`) + 화난 얼굴 사진이 잠깐 (`face_angry.jpg`)
  - 유령 잡기 → 킥킥
  - 🍓 딸기(가장 중요한 아이템) → 킥킥 + 웃는 얼굴 사진이 잠깐 (`face_happy.jpg`)
  - 단계 클리어 → 큰 웃음 (`laugh_big.mp3`)
- 🍼 젖병을 먹으면 잠깐 동안 유령을 잡을 수 있고, 가끔 나타나는 🍓 딸기는 보너스 300점
- 목숨 3개, 단계가 오를수록 조금씩 빨라짐, 최고 기록 저장

## 조작

- 컴퓨터: 방향키 또는 WASD
- 휴대폰: 화면 밀기(스와이프) 또는 화면 아래 방향 버튼
- 🐢/🐇/🚀 버튼으로 속도 조절 (느리게 · 보통 · 빠르게, 기본값 느리게, 선택은 저장됨)
- 갈림길 반 칸 전후에서 방향을 눌러도 바로 꺾임
- 🔊 버튼으로 소리 켜기/끄기

## 실행 방법

```bash
open index.html   # 또는 브라우저에서 직접 열기
```
